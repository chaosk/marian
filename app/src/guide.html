/event

Starts an event. Marian asks in a DM where to post it, the title, the description, when it starts, when it ends, and how often it repeats. You finish it there, or change the signup options and the other details first. Signup options start from the server’s default preset, Accepted, Declined, and Tentative unless it has been changed.

/edit

Changes one event. You pick the event, then any of the title, the description, the start time, the length in minutes, and the channel. A start can look like “tomorrow at 7pm”, “friday 9am”, “oct 20 at 8:00pm”, or “in 2 hours”.

/reminders

Turns your reminders on or off. Leave the choice empty to see whether you get them.

/response

Adds, removes, or moves a person’s signup. Each one asks for the event, the person, and the signup option, and lists the choices.

/settings

Changes one server setting. A server manager picks the setting. Each one has its own fields: the default reminder, a 24-hour clock, archiving, event threads, names on the Discord post, a temporary attendee role, the waitlist, the digest (off, daily, or weekly), how early a series date is posted, and which role may create, edit, delete, manage channels, or manage signup options.

/signup_options

Lists the server’s attendance types, adds one with a name and an emoji, or removes one nothing uses. A new type counts as attending unless you say otherwise. Renaming and the attending switch are on the Presets page.

/signup_presets

Lists presets, saves one from type names separated by commas (a name the library doesn’t have is added to it), or removes one. The Presets page also sets capacities, role limits, and the default preset.

/channel

Creates an event channel in Discord. You give the name. An event channel is a Discord channel Marian keeps for events. With purge on, posting or deleting an event removes other messages, and pinned messages stay. Other Discord channels arrive from the server as text channels.

/google

Connects a Google Calendar, pauses or resumes automatic updates, adds one event, or disconnects. Connecting and automatic updates are also on the Google Calendar page. Each person keeps a private feed of events they created and events they accepted.

/sort

Reverses the order of the posts in an event channel. Use it in that channel. Other channels stay as they are.

/help

Explains /event, and links to this page for the rest.

Routines

A weekly poll is a routine on the dashboard.
